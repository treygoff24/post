## Maintainer decisions and bug verdicts

- **No proposed deletion changes production behavior or the published contract.** `CONTRACT.md:184-205,587-683` documents channel storage, reads, crossed sends, and join floors; `:436-443` documents archived search. Do not change those terms or `src/channel_archive.rs` archive semantics as part of this test cutover without Trey's decision. Removing the two proven test-only methods is a non-behavioral source cleanup; no user-visible contract depends on either.
- **No product bug confirmed by source review.** The archive state machine does use a sidecar, treats only a newer conversational message as resurrection (`channel_archive.rs:88-119`), writes only for explicit state changes (`:154-204`), and fails open in listings while doctor reports corruption (`channel.rs:1922-1925`, `doctor.rs:751-758`). The empty-archive and non-member archive tests exercise real branches.
- **Test defect confirmed:** the blocked-route unit tests its own predicate (`channel.rs:2180-2201`), so it can pass if the production join guard at `:710-743` is removed. The grep test does not exercise case folding or regex syntax. The empty catch-up test does not exercise a positive batch. These are coverage defects, not observed product failures.
- **Test-only seam caller searches:** `rg -n 'list_channels\(' src tests --glob '*.rs'` found only its definition and `src/channel.rs:2236` test call; production `src/commands/channels.rs:12` and `src/commands/search.rs` use `list_channels_with(..., Scan::Tolerant)`. `rg -n '\.has_seen\(' src tests --glob '*.rs'` found only `src/channel_state.rs:919-920`. `rg -n 'render_text\(' src/commands/chat.rs` found the `#[cfg(test)]` wrapper at `:1812` and unit calls at `:2948-3324`; production calls `render_text_cached` (`:1314,1410`). `rg -n 'mark_own_message_seen\(' src tests --glob '*.rs'` found production `chat.rs:2361` and three unit calls, all with `OWN_SEEN_LOCK_BUDGET`. `rg -n 'signed_age_minutes\(' src tests --glob '*.rs'` found real mailbox callers `src/mailbox.rs:1746,1822`; that unit is misplaced but not dead production code. `rg -n 'archive.json|archive_invalid|archive' src/commands/doctor.rs src/commands/search.rs src/commands/channels.rs` confirmed live archive readers and diagnosis.
