## Maintainer decisions, bug verdicts, and open verification

Removing or changing that documented transition story requires the maintainer's ruling. This review does not authorize a `CONTRACT.md` or `docs/` contract edit.
- **Product bug verdict:** no current fence defect established by source inspection. The `_ => false` fallback in `classify_write` (`src/migration_fence.rs:666`) is a future fail-open maintenance risk; current command arms include bridge, and `src/commands/bridge.rs:103` takes its own admission. It is not a reproduced bug. The contradictory framing assertion message and obsolete `search_unavailable` branch at `tests/cli.rs:7471-7504` are test defects. The retired cursor path in `tests/catchup.rs:362-363` is another test defect.
- **Caller search used:** `rg -n 'fence\(|activate\(|write_state_locked\(|conservative_read_mode\(|read_only_must_not_mutate\(|admit_generation\(|admit\(|is_enrolled\(' src tests bridge --glob '*.rs' --glob '*.py'`. These are source searches, not runtime proof.
