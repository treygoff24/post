The dispatcher separately includes the error text as `participant_error` (`src/commands/mod.rs:658-678`), while doctor emits `participant.binding.invalid` with the original suggested fix (`src/commands/doctor.rs:90-111`). Exact caller searches: `rg -n 'participant::resolve|participant.binding.invalid' src/commands/{who,doctor}.rs`; `rg -n 'participant_error|tolerates_resolution_error' src/commands/mod.rs`; `rg -n 'malformed:participant' tests/routing.rs` (doctor fixture at `:2464`, no matching who check). This is a low-severity misleading acting-row fix, not lost error information.

Exact search: `rg -n 'participant::load|load_owner_with_rooms' src/commands/doctor.rs`; the second owner call is on the same `rooms` value. No production edit belongs in this read-only audit.
